# Factbox — website

The public site for **Factbox**, a daily history app: one story a day, told as
a stack of cards, every card citing where it came from.

| Page | What it is |
|---|---|
| `index.html` | Landing page |
| `story.html` | A full story, readable in the browser — the thing social traffic lands on |
| `privacy.html` · `terms.html` · `support.html` | The three URLs App Store submission requires |

Static HTML with no build step and no dependencies. Published with GitHub Pages.

The app itself lives in a private repo. Nothing here is app source.
